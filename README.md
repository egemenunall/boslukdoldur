# HSD Boşluğu Doldur

Eğlenceli çok oyunculu kelime oyunu - HSD Network

## 🎮 Canlı Demo

[Buradan oyna!](#) (Railway'e deploy edildikten sonra eklenecek)

## 🚀 Özellikler

- ✅ Gerçek zamanlı çok oyunculu oyun
- ✅ Mobil ve masaüstü uyumlu
- ✅ 20 farklı soru
- ✅ Modern HSD tasarımı
- ✅ WebSocket ile anlık senkronizasyon

## 🛠️ Teknolojiler

- Next.js 14
- Socket.io
- TypeScript
- Tailwind CSS

## 📦 Kurulum

```bash
npm install
npm run dev
```

## 🎯 Nasıl Oynanır?

1. Oda oluştur veya katıl
2. Boşluklu cümleye yaratıcı cevap ver
3. Hangisi doğru cevap tahmin et
4. Puan topla ve kazan!
